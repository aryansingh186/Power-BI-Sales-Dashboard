# 📊 Interactive Power BI Sales & Profit Dashboard

An end-to-end interactive Power BI analysis dashboard designed to evaluate sales performance, regional profit margins, and product profitability.

---

## 📌 Project Overview

This dashboard provides an executive summary of sales metrics to help business stakeholders make data-driven decisions. It enables deep exploration of sales distribution across regions, product categories, and monthly performance trends.

---

## 🛠️ Data & Tools Used

* **Business Intelligence Tool:** Microsoft Power BI Desktop
* **Data Sources:** `sales.csv`, `Sales_Cleaned.csv`
* **Data Preparation:** Power Query (Data cleaning, type casting, missing value handling)
* **Calculations:** DAX (Data Analysis Expressions) for custom metrics and aggregations

---

## 🚀 Key Features & Insights

* 📈 **Monthly Sales Growth:** Tracks sales volume and revenue trends across months to identify peak performing periods.
* 🌎 **Regional Profit Margins:** Breakdown of profit across key sales regions (East, West, North, South).
* 📦 **Product Performance:** Comparative analysis of sales volume across top product categories (Printers, Tablets, Laptops, Monitors, Mobiles).
* 🎛️ **Interactive Slicers:** Dynamic filtering by region and product line for granular analysis.

## ⚙️ How to View the Report

1. Download the `Sales & Profit Dashboard.pbix` file from this repository.
2. Open the file in Microsoft Power BI Desktop.
3. Use the top slicers to interactively filter data by region or month.
